During my second-year Master’s program, I completed a data project using a synthetic dataset from Kaggle to predict calories burned based on features such as session duration, gender, age, and sport experience. I applied multiple linear regression and compared three models (Linear Regression, Lasso Regression and Ridge Regression).
I focused on optimizing the RMSE for the best predictive performance. A large part of the project involved handling missing data, normalizing features, and ensuring reliable, clean datasets. The analysis was carried out in Python 3.12 using Jupyter Notebook, giving me hands-on experience in regression modeling, feature selection, and data preprocessing.

Link to the dataset : https://www.kaggle.com/datasets/valakhorasani/gym-members-exercise-dataset
